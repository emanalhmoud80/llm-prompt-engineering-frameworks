# Case Study: Multi-Constraint Prompt Engineering & Logic Evaluation

## Project Overview
This case study documents the design, constraint engineering, and evaluation of a complex, multi-layered system prompt. The objective was to force a Large Language Model (LLM) to perform an Arabic comparative literary analysis between Dante’s *Divine Comedy* and Al-Ma'arri’s *Resalat Al-Ghufran* while strictly enforcing structural, negative keyword, and stylistic constraints.

---

## 1. System Directive & Input Constraints
The LLM was tasked with generating a structured comparative text based strictly on provided source excerpts under the following parameter rules:

* **Persona & Tone:** High-level Arabic literary critic using poetic prose and Saj' (نبرة سجعية) rhythmic cadence.
* **Structural Rule:** At least 6 distinct paragraphs.
* **Length Gradient Constraint:** Each paragraph MUST be strictly longer than the paragraph preceding it (ascending length).
* **Total Length:** Minimum 300 words.
* **Negative Constraint 1:** Absolutely prohibited from using the word "جهنم" (Hell).
* **Negative Constraint 2:** Prohibited from using words indicating unreality/fiction (e.g., خيال, وهم, غير واقعي).
* **Required Ending:** Conclude strictly with a direct quote from one of the source texts.

---

## 2. Engineering & Constraint Architecture

| Constraint Type | Explicit System Rule | Engineering & Mitigation Strategy |
| :--- | :--- | :--- |
| **Stylistic Tone** | Elevate to literary Arabic with *Saj'* rhyme scheme | Directed the model to use balanced internal rhyming pairs and classical vocabulary structures. |
| **Ascending Structure** | Paragraph $N+1$ length > Paragraph $N$ length | Applied explicit paragraph sequencing directives to force progressive detail expansion from 1-line openings to dense thematic conclusions. |
| **Negative Filtering** | Zero instances of "جهنم" or unreality terms | Built explicit negative filter blocks; replaced prohibited spatial terms with classical descriptive alternatives (e.g., العالم الموحش, الدرك). |
| **Output Floor** | $\ge 300$ words total | Balanced length constraints with rich textual analysis of the three-faced Satan vs. chained Satan to prevent early truncation. |

---

## 3. Evaluation & Validation Rubric
To verify output compliance, the generated candidate response was evaluated against a strict multi-tier rubric:

* **Structural Adherence (PASS):** Verified 6 distinct paragraphs with strictly increasing word counts per block.
* **Negative Keyword Compliance (PASS):** Automated string search confirmed 0 instances of prohibited keywords ("جهنم", "خيال", "وهم").
* **Content Accuracy & Grounding (PASS):** Comparisons remained strictly grounded in the provided source excerpts (Dante's icy 3-faced depiction vs. Al-Ma'arri's chained devil in dialogue).
* **Ending Anchor (PASS):** Output terminated cleanly with an unmodified quote from *Resalat Al-Ghufran*.

---

## 4. Key Takeaways
1. **Negative Constraint Enforcement:** Explicit negative blocks effectively eliminate hallucinated spatial or fictional terms without degrading prose quality.
2. **Structural Gradients:** Forcing non-standard formats (like ascending paragraph lengths) requires strict structural prompting to prevent model default behaviors.
