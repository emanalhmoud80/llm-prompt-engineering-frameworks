# LLM System Prompt Engineering & Evaluation Portfolio

Structured system prompts, evaluation frameworks, and edge-case handling for complex Large Language Model (LLM) instruction-following.

---

## Overview
This repository showcases structured prompt engineering frameworks designed to optimize LLM performance on multi-constraint tasks, complex logic evaluations, and strict formatting requirements.

## Core Capabilities
* **Strict Constraint Enforcement:** System prompts enforcing exact word counts, structural constraints (JSON, Markdown), and negative keyword filtering.
* **Edge-Case Resilience:** Frameworks engineered to eliminate hallucinations, prevent logical breaks, and handle subtle prompt edge cases.
* **Evaluation Frameworks:** Multi-step rubrics and criteria for scoring LLM output quality, accuracy, and constraint adherence.

## Repository Layout
* [`/prompts`](./prompts): Structured system prompt templates and production-ready instructions.
* [`/case-studies`](./case-studies): Detailed breakdowns of complex instruction-following frameworks and test results.
